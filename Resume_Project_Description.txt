PART 2: COMPLETE END-TO-END SYSTEM FUNCTIONING & CORE ARCHITECTURE
--------------------------------------------------------------------------------

1. SECURE AUTHENTICATION & PROFILE Personalization FLOW
   • Signup: Captures user details, enforces secure password complexity, and initiates account registration.
   • Email Verification (Activate): Integrates an activation flow that validates user accounts, preventing bot registrations and securing downstream APIs.
   • Login (JWT Auth): Authenticates credentials, stores a security token, and redirects to dashboard routes. ProtectedRoute controls prevent session hijacking or unauthenticated access.
   • Profile & Cloudinary Hosting: The Settings dashboard allows real-time edits. Users can select or upload custom profile images directly to Cloudinary via REST integrations, persisting the hosted remote URL to the user object.

2. DYNAMIC KPI DASHBOARD (HOME OVERVIEW)
   • Financial Aggregator: Interrogates the `/dashboard` backend endpoint to compile real-time summaries of Cumulative Earnings, Cumulative Spendings, and Net Balance (Net Worth).
   • Net Worth Distribution (Pie Chart): Features a custom Recharts outer-bordered Pie Chart showing the percentage-based breakdown of financial standings. Utilizes customized tooltip rendering and precise hover transitions.
   • Real-Time Transaction Feed: Aggregates recent earnings and spendings, categorizing them visually with custom emojis, timestamps, and currency formatters (configured to Indian Rupees - INR).

3. MODULAR CASH-FLOW TRANSACTION MANAGERS (EARNINGS & SPENDINGS)
   • CRUD Controllers: Separate portals (`Income.jsx` and `Expense.jsx`) present clean transaction grids containing transaction names, category labels, exact dates, and values.
   • Transaction Forms: Reusable, controlled components with validation layers. Supports custom input structures, preventing empty fields or invalid values before dispatching payloads to `/incomes` or `/expences`.
   • DeleteConfirm Modals: Intercepts destructive delete triggers, implementing safety verification overlays before clearing transactional records from database states.

4. USER-CUSTOMIZABLE CATEGORY BUILDER
   • Flexible Categories: Allows users to establish customized labels to classify earnings and spendings (e.g., Food, Travel, Rent, Investments).
   • Emoji Picker Integration: Incorporates an interactive Emoji Picker overlay allowing users to tie custom icons to custom categories. Emojis render dynamically across all list and overview pages.

5. ADVANCED QUERY FILTERING & ANALYTICS
   • Multi-Variable Filters: Implemented in `Filter.jsx` to let users execute rich searches on transaction logs.
   • Filter Criteria:
     - Transaction Type Toggle (Earnings vs. Spendings)
     - Start Date & End Date Range limits
     - Keyword search (matches transaction names or descriptions)
     - Sort Field Dropdown (Date or Amount)
     - Sort Order Toggle (Newest-to-Oldest or Oldest-to-Newest)
   • Real-Time Summary Stats: Immediately displays the cumulative total and match count for active search configurations.

6. AUTOMATED FINANCIAL REPORTING & SMTP PIPELINE
   • Excel Download Engine: Streams transaction history directly into a styled Microsoft Excel workbook (`.xlsx`) generated by the backend and received as a blob stream on the client.
   • Automated SMTP Mailer: Triggers a secure backend service via standard REST calls that compiles Excel reports on-the-fly and sends them directly to the user's verified email address as an attachment.
